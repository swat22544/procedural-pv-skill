# 技巧选用与组合判断

> 公开版阅读约定：`<…>` 是待配置的路径占位符；文中原项目文件名属于所指参考仓库或本地案例，不表示随本 skill 附送。原研究的抽样与运行记录仅说明当时的验证范围，不代表你的环境已经通过。跨机器使用先读 [环境接入](environment-setup.md)。

用于新视觉方向、新分镜、较大改编，或出现“每个效果都很好但合起来混乱”的情况。它把已有条件分散在各专项中的判断汇总到选型阶段；详细实现仍查原参考。小修不必重做选择表。

## 1. 区分需要守住的条件与可选表达

用户的本次要求、既有片子的有效设定和当前歌曲先于参考偏好。只对会改变方向的缺失信息提问；普通审美取舍由模型作出并给出简短依据。

同一时钟、资源就绪、正确文字布局、确定性导出、真实媒体验收属于生产条件。环绕、粒子、形变、分屏、聊天、世界文字、版画、故障、景深和运动模糊属于按需选择的表达或渲染手段。“选少一点”不能删掉必要检查，也不能把低强度当作普遍正确。

先明确两层：

- **整片/章节规则**：情绪走向、材料与字形语言、对象身份、运动节奏、空间逻辑。章节可以有意不同；说明何时切换、观众凭什么识别，而非强行统一配色。
- **当前镜头任务**：读一句话、看清动作因果、发现空间关系、感受压迫/速度、表现主观变化、比较两件事、停顿或纯粹跟随音乐。抽象律动是合法任务，不必为每个点编造物理因果。

## 2. 四份来源怎样进入选择

下表是已有研究的检索优势，不是作者风格的完整定义、能力排名或互斥分类。同一种方法可能出现在多份参考中；先选任务，再找最适合的实现案例。

| 当前问题 | 优先检索的研究 | 可借用的方法 | 不随之自动采用 |
|---|---|---|---|
| 同一结构换视角后应该让观众多理解什么？ | [pdoom 镜头方法](pdoom-camera-method.md)、[设计案例](pdoom-design.md) | 观察任务、位置/目标/焦距分工、追踪与释放、阅读落点、空间/材料文字 | 纸色橙黑、精密线框、全片三维、每句换机位 |
| 已确定要连续的两个镜头怎样接住同一状态？ | [FrostNova 转场](frostnova-transitions.md) | 同一歌曲时间、共享几何/相位、投影锚点、相机与文字分别换手 | 强制一镜到底、所有对象身份守恒、粒子聚散、固定 glide/whip 时长 |
| 一个元素的动作怎样造成另一个元素的改变？ | [Misaka 元素叙事](misaka-motion-method.md) | 来源→载体→到达→持久结果→后续动作，关系类型与双画面主次 | 任意物体强行形变、所有镜头分屏、旧题材的终端与角色 |
| 文字怎样成为发言、主观画面或有结果的操作？ | [Nyanko 歌词案例](nyanko-lyric-cases.md)、[歌词方法](lyric-dramaturgy.md) | 说话者身份、现实/内心切换、文字动作、复现时改变状态 | 每句做成聊天框、固定版画材料、全屏故障、复制角色色彩 |

例如，一个平面版画镜头可以借 pdoom 的“读完再释放视线”，借 FrostNova 的同一时钟，仍保持自己的版画语言；不需要添三维房间或网格来证明使用了这些方法。

## 3. 先用任务筛选，再决定具体技巧

同一镜可能命中多行，先选主导任务，其他行只在有帮助时参与。下表的退路也是正式设计选择。

| 观看任务与采用条件 | 合适候选 | 放弃或推迟的信号 | 可替代做法 |
|---|---|---|---|
| 空间层级、遮挡或尺度关系确实会因视角变化而显露 | 斜视、低机位、推进、拉远、有限环绕 | 只是让一个平面图转动；新机位看不到新关系；读窗被透视吃掉 | 平面重构图、局部放大、定镜；实现查 [机位表](pdoom-camera-method.md) |
| 需要跟住移动主体，或迟一步才理解其影响 | 跟拍、目标先行、有限迟后、停追踪 | 主体本身已高速变形，镜头再追会失去参照；没有稳定落点 | 镜头稳定，让对象运动；先交代参照再跟随 |
| 前后镜明确共享对象、路径或某项状态 | 共享几何、载体接力、锚点匹配 | 只因轮廓相似便声称同一对象；接上后旧结果被抹掉 | 改为形态/语义匹配，或硬切；实现查 [承接类型](frostnova-transitions.md) |
| 内容真的从容器、字孔、屏幕或通道进入另一尺度 | 门洞/递归穿入 | 没有入口与目的地关系，只想替每次切镜加炫技 | 按动作/拍点切换或构图匹配 |
| 时间、地点、态度突变或需要节奏标点 | 硬切、短促重构图；有声音/情绪延续时可叠化 | 为了“连贯”给无关场景伪造共同几何；叠化让两句字争读 | 保留清楚切断；切后给定位线索与读窗 |
| 元素确实传递内容、改变目标或留下结果 | 描线、连接、折叠、搬移、改写、消耗、粒子载体 | 动作结束没有结果；替换成任意飞行物也完全一样 | 保留直接动作，省掉中间形变；纯装饰运动不冒称因果 |
| 同时看两侧能形成比较、因果或反差 | 分屏/内嵌画面 | 两侧各自有长句和复杂动作，观众无法确定读哪边 | 轮流占主画面，或分时强调；查 [Misaka 主次](misaka-motion-method.md) |
| 歌词长、快、信息重要，或主体运动已很复杂 | 稳定阅读层、分句排版、有限重点词 | 逐字进场压缩了全文读窗，关键词替代造成漏词 | 提前建立布局、减弱入场、稳住文字；不套通用固定读秒 |
| 文字所属载体在故事中有功能，且角度、尺寸、遮挡可控 | 路牌、纸面、轨道、建筑文字、曲线文字 | 全文只有侧背面可见；为了融景让唱词失读 | 保留世界里的强调词，完整词放同主题稳定层；查 [依附与读窗](lyric-dramaturgy.md) |
| 某句的发言、执行、抹除、强调或含义转折就是本镜事件 | 消息/回执、材料文字、独立文字镜头、主观插镜 | 没有说话者或后果，却强套聊天；孤立大字无法承接上下文 | 用叙述文字或普通场景；有真实转折时再给文字独镜 |
| 音乐/状态确有失稳、断裂、冲击或高密度高潮 | 局部故障、错版、粒子、闪切、亮度/密度变化 | 全片恒定开满；主信息被破坏却没有恢复或接管安排 | 局部化、缩短、分段增加，或让构图/剪辑承担冲击 |

工具在表达决定之后选：文字/平面无需为“高级”升级三维；实体遮挡、灯光和材质确有需要时再选择相应引擎。已有原生工程、只换音轨等任务沿既有路线；具体入口见 [生产流程的工具表](production-workflow.md)。

## 4. 多种方法组合时，按注意力与时段处理冲突

“一个主导变化”指观众有可追踪的重点，不是只能启用一个系统。例如“写字的光点进入纸面”可同时用跟拍、字形揭示和折纸，三者共享同一目标与进度就能协作；它们若各自旋转、爆发、变色，便会争夺注意力。

| 竞争情况 | 优先处理 |
|---|---|
| 高速机位 + 新出现的长句 | 先让镜头落定再完成阅读，或把完整句稳定在屏幕上 |
| 字体强变形 + 主体也需要精确追踪 | 分时让出主导权，或降低其中一方的变化强度 |
| 精确对象交接 + 粒子化/区域采样 | 先明确身份/数量是否真的保持；需要精确交接时使用稳定映射，不用泛化粒子效果掩盖错误 |
| 分屏 + 双侧同时出现新信息 | 分配先后阅读顺序、亮度/尺寸主次；无同时比较价值就轮流呈现 |
| 强故障/景深/模糊 + 必须读清的文字 | 让效果避开读窗，或给清晰文字另设合成责任；若失读本身是意图，预先/事后交代应被理解的内容 |
| 四份参考的材料、配色、界面习惯互不相容 | 将借用的方法译成本片语言；若混合本来就是主题，就用章节、视角/角色状态或重复母题解释换风格 |

这里没有统一的特效个数、高潮亮度、读秒或“70/20/10”比例。密集度、变化速度与文字负担分开考虑。大量物体也可以围绕同一焦点；稀疏画面也可能因为各层各做各的而混乱。不要为了展示学过四份资料而分配出场额度，也不要把有意的多风格作品改成单一风格。

## 5. 把取舍留在分镜里，并用短片复核

在原镜头表中补几行即可，不新增强制审批或重复文档。连续复用规则的镜头可合并记录；只有值得争论的候选才记录弃用理由。

```text
本段目标与音乐/歌词事件：
沿用/切换的视觉规则与原因：
主导手段 → 为何能完成任务：
辅助手段 → 如何配合或错开：
不采用的显眼候选 → 不适用的具体原因：
读完/动作落点/交接；出现什么问题就减弱、换法或删除：
```

看片时先问：第一眼注意到的是计划中的重点吗？完整句与动作结果能被理解吗？切换后的新信息是否值得这次镜头运动？若删掉一个效果，情绪、节奏、理解和承接都不受损，就没有保留它的充分理由。方案仍不确定时，只对有争议的短窗口做有/无该效果的比较，不自动扩展成整片多方案重渲染。

**应用例，非新模板：**《把回声点亮》的地面歌词先读再转斜视，采用的是空间揭示；“没有回答”段需要等待，用定镜和音乐留白即可；路线→折痕存在可追踪的材料承接，才做形变。它的纸色、光点和橙青身份属于这支片，不成为下一首歌的默认设定。
