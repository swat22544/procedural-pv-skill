# 新环境接入

本 skill 只提供制作方法、工具路由和研究笔记，不附带渲染引擎、原曲、字体、模型权重、参考影片或两个本地案例的源码。先判断任务只是讨论/分镜，还是需要实际产出媒体；前者不必安装整套工具。

## 首次制作

1. 读取当前工程的入口、依赖锁定文件、音轨、歌词、字体和交付要求。缺少素材时继续做不依赖它的工作；对会改变成片的缺项明确说明，不替换成无关旧歌。
2. 按 [技巧选用](technique-selection.md) 先决定观看任务，再用 [工具路线](local-tools.md) 选择一条主渲染链。已有工程优先保留其有效入口。
3. 将实际可执行程序、版本、参考仓库位置、资源和输出目录记在项目自己的配置或 `production-environment.md`。不在技能里写回个人磁盘路径，不把秘密写入共享配置。
4. 核对字体字形和资源加载，输出一个代表性静帧，再输出含运动、文字与切点的短片；验证确定性、帧数、音轨、解码及实际画面。启动成功不代表导出成功。
5. 冻结这次通过的版本、随机种子、输入哈希、时间口径、颜色设置与输出参数。新版本另存；确定兼容再升级。

## 占位符

这些名称用于阅读文档，**不是程序会自动展开的环境变量**。运行命令前换成当前环境的真实路径；文档中的历史文件只在其原工程里存在。

| 名称 | 含义 |
|---|---|
| `<PROJECT_ROOT>` | 当前正在制作的独立工程 |
| `<MULTIPLANE_BIN>` | 当前环境的 Multiplane CLI/启动器；npm 安装可用 `npx multiplane` 调用，不能把两个词塞进 PowerShell 的单个可执行路径参数 |
| `<FFMPEG_BIN>` / `<FFMPEG_DIR>` | 支持所需编码器的 FFmpeg 程序及其目录；FFprobe 单独核对 |
| `<PYTHON_BIN>` / `<PV_PYTHON_BIN>` / `<ALIGN_PYTHON_BIN>` | 当前工程、几何渲染、音频分析各自明确的 Python 环境；允许合并，但不假定依赖已经齐全 |
| `<PV_PYTHON_ENV>` / `<MANIM_BIN>` | 按需建立的 Python 环境和 Manim 入口 |
| `<BLENDER_BIN>` / `<BLENDER_MCP_BIN>` / `<BLENDER_ADDONS>` | Blender 程序、匹配的 MCP 服务和 addon 位置 |
| `<THREE_MODULE_ROOT>` | 同一固定版本的 Three.js 及 addons；不能跨版本拼接 |
| `<INSTALLED_SKILLS>` | 当前宿主实际发现的技能目录 |
| `<REFERENCE_ROOT>` | 读者自行取得的参考仓库，尽量切到研究注明的提交；不是本仓库的子模块 |
| `<LOCAL_WORLD_PV>` / `<LOCAL_MACHINE_LOVE_PV>` | 作者的两个本地实践工程，仅在用户提供时才能继续；它们不在发布包中 |
| `<USER_AUDIO>` / `<USER_REFERENCE_VIDEO>` | 用户有权使用的音轨和参考视频 |
| `<PRIVATE_STUDY_ARCHIVE>` | 作者未公开的历史研究与验证记录，只用于说明来源；不要要求读者创建空目录冒充证据 |
| `<LOCAL_TOOL_INVENTORY>` | 如存在，用户自己的工具索引；没有时通过当前环境发现工具 |
| `<SKILL_VALIDATION_ENV>` / `<CINEMA4D_BIN>` / `<HISTORICAL_FFMPEG_CANDIDATE>` | 历史案例中的辅助或旧入口，不属于默认必装项 |

## 缺少工具时

新网页镜头默认使用 Multiplane；先读其当前官方文档和配套 skill。不能安装或用户指定了其他工具时，说明实际限制，保留镜头的绝对时间接口，并使用用户认可的导出链。不要把浏览器实时预览当作已导出视频。

Blender 可以通过后台 `bpy` 脚本渲染，MCP 只是可选交互入口。未连接 MCP 时仍可完成适合后台脚本的工作；当前场景编辑需先检查用户工程。插件的素材搜索和付费生成不因安装而自动获得使用授权。

原研究中的“通过”“本次”“当前”是相应日期与具体机器上的记录。新机器重新检查自己的环境与实际产物；历史帧率、配色、字幕、歌曲结构和用户偏好只是案例条件。
