## 1. 盾牌里的点被装进权重格，权重再聚成出生种子

源码：[V2/s_boot.py:C02/C03](https://github.com/MisakaZentai/world-execute-me-dsh-pv/blob/a598092a1b1db91fa43961a81269353d13419f6f/film/tui_pv_world_execute_20260926/continuity_full_v2/s_boot.py#L173)，`scenes_boot.py:171–183,224`、`dsh_patch_fix.py:418–421`。

C02 在3.620238秒切入：盾牌点按行列排列，每点有稳定 `cell=k`、出发和到达时间。点沿二次曲线飞到 `cell_center(k)`，飞行后45%逐渐变成目标格的宽高；光晕随着落地衰退。旧盾牌在普通层隐藏，搬运由载体层接管。

盾牌外沿另沿弧长重采样，对应矩形边框周长，额外加入四角的参数位置以保持锐角。内点→数据格、外沿→容器框是两个并行动作，最后组成可运行的界面。

`setup` 把同一 `landed()` 表交给后镜：格子在该点真正到达后点亮，剩余格再依次加载。随后 C03（5.235623秒）将161格收为一点，琥珀转蓝，再把种子送到主体位置；落地后才径向揭示内容。最终 dsh 版长出的是窗口，原亮环前沿在 cover 内关闭。

**可迁移选择**：动作的结果进入持久输入 `arrivalTime[id]`；让容器和内容有各自路径但共享落点。C02 是索引接力，C03 是多→一→多的语义聚合，两者不同。

## 2. 启动字 → 词流 → 损失曲线 → 第一流水格

源码：[V2/cuts.py:C08–C10](https://github.com/MisakaZentai/world-execute-me-dsh-pv/blob/a598092a1b1db91fa43961a81269353d13419f6f/film/tui_pv_world_execute_20260926/continuity_full_v2/cuts.py#L100)，`s_pretrain.py:setup`、`scenes.py:loss_at/pipe_cells`。

三个切点为16.081777、19.543315、23.235623秒：

1. 启动字实际字体 mask 内抽出26个词块起点，沿曲线飞入词流；同时预算文字移到计数器位置。主视觉与数值标签分别交接。
2. 词流向曲线原点汇聚，远处先走，接近时变小变亮；原计数器缩到图表下方成为标签。新画面沿原点向外逐格显现。
3. 损失曲线反向缩短，端点沿同一 `loss_at()` 吃掉曲线，回到原点后再移向流水第一格并扩成块。流水的后续计划等待该块落地后展开。

**连贯来源**：每镜消耗上一镜留下的东西；“文字被读入→形成学习曲线→变为执行单元”给几何运动以语义方向。背景揭示服务原点，未抢走载体的注意力。

**准确边界**：C08 词流落点取自未来某个预采样时刻，后镜仍流动，靠近似匹配与短淡交接管，并未保持 live token ID；曲线端点到第一格则有明确位置函数。复制时对移动目标按真实 landingTime 求值，或跟踪稳定目标 ID。

## 3. 流水格 → 鲸鱼字 → 点云 → 头像；向量 → 圆 → 正弦 → 切线

源码：`V2/cuts.py:C11–C17(263–583)`、`scenes.py:276–318,401–500`；最终头像目标/起点修订在 `DSH/dsh_patch_fix.py:345–379`。

前半链在26.466392–31.601008秒：流水格按排序错峰飞向鲸鱼字形，中途换字；鲸字位置变成1400点的出发区域，点继续沿后镜的聚类公式运动；点云再飞入左窗头像区域，向量场延迟输出以留出“吸收”的时间。

这不是粒子数量守恒：C11 的排序映射会随目标字形改变；C12 用取模把多点分配到有限鲸字中心；最终 C13 的目标是未来头像矩形内的网格，不是精确头像轮廓。可学习可识别的分裂/汇聚，但需要稳定身份时应另建 ID 映射。

后半链选择一个主通道继续：从向量网格提取实际笔画，收窄成杆并旋转到第0圆的指针；其他圆从它生长再收回。第0圆扩成周长图解，圆周点逐步撤掉、等长直线增长；直线转为第2路正弦，再让该路接入 `tangent_curve/tangent_state`，主体落到实时 `rider_pos` 后继续走。

**关键差别**：圆周→线是按角度移除与按长度增长的图解，不是每个圆周粒子沿物理展开路径移动；正弦→切线的终端则调用后镜相同公式。最终起飞点已改为头像中心，右侧仍可保留舞者。

**窗口反例**：C14/C15 在34.243315–34.377931秒重叠，首个 active 优先；C14 最晚圆应在 T+1.573077 完成，但自身 post 只有1.45。迁移时计算所有错峰元素的结束，不照抄窗口或将全部接点称为数学无缝。

## 4. 撞墙条 → 电流 → 注意力矩阵 → 曲面，选中格继续成为球

源码：`V2/cuts.py:C19/C20(614–677)`、[s_sft.py:C21/C22](https://github.com/MisakaZentai/world-execute-me-dsh-pv/blob/a598092a1b1db91fa43961a81269353d13419f6f/film/tui_pv_world_execute_20260926/continuity_full_v2/s_sft.py#L233)、`scenes_sft.py:53–200`。

蓝条撞墙后，越界部分碎开，剩余长度写入后镜 hook，避免爆炸结束后旧条又长回来。条被分为8带，厚度渐退成线，逐采样点接向 AC/DC 波形；波相位仍读同一歌曲时间。

47.235623秒的 C21 把8条线各切12段：先将段内高度拉到平均值，形成采样保持短线，再扩成方格、重排到12行中的8行；缺的4行从已到达行展开。后镜用到达门控显示行，上三角遮罩稍后再启动。矩阵随机数不是原波形数值的真实 attention 运算。

49.081777秒的 C22 在共同局部坐标上将矩阵躺倒、旋转、弯成碗面。格子翻转缩小，它对应的区域才生成曲面点；指定(9,9)格变蓝，球从该格的同一平面坐标出发，沿螺旋向低处滚落。

`dizzy_rot(t)` 被转场与后镜共用，以平滑速度的积分计算角度。拖尾保存过去的世界位置，再按当前视角投影，因而不会像屏幕贴纸。这里是2.5D仿射投影，不是透视摄影或物理训练模拟。

**可迁移选择**：先分段/量化，再重排，再赋予新语义；形态变化在共享坐标系中发生，后动作选择其中一个明确单元作为种子。

## 5. 同一条回答被纠正；相同动作后来改变了操作者

源码：`DSH/batch_a1.py:159–172`、`batch_a2.py:47–68,99–118`、`batch_a3.py:63–95,127–169`、`batch_b.py:53–114,132–167`、`batch_e.py:190–222,317–326,640–677`。

A2 首轮直接使用 A1 的发送时刻、同一文本和输出速率，跨16秒章节继续同一轮输出；A3 又用 A2 最终回复排版旧历史。身份连续由头像、消息内容和进度共同承担，不靠背景同色。

A3 失控输出在确切上限截断；B 通过 `ramble_final()` 读取同一截断结果再划红线。旧文先被选择/删除线标记并保持 .30 秒，随后退去，新字打入；下一轮只改错的后缀而保留正确前缀。布局采用文流重新排列，不是每个字符都做几何 morph。

B 建立“用户反馈影响下一次回答”的语法；D/E 随后复用相同控件，但点赞变成角色自己点亮、输入位置变成角色伪造、红笔变成角色修改规则。角色色、caret 和动作标签告诉观众现在是谁在做这件事。

**可迁移选择**：重复动作词，改变发起者或结果，形成意义演变。跨章节直接读取 terminal state；不要手写一段貌似相同的旧文本或归零已有输出进度。所有训练/工具行为在本片都是离线编排。

## 6. 先写入具体记忆，后来回忆才有来历

源码：`DSH/batch_c.py:105–145,243–310`、`dsh_patch_mem.py:sprite_specs/row_layer/bubble_row`。

C 把之前交互写成具体文件：第一次消息、猫图、笑声、最后一条话等；以后角色切换时，旧记录被写入新提示。连续性由内容和文件名跨会话保留，并非整条聊天页永远不变。

118秒后的光标根据逐词事件跳到对应文件行，行反白、内容气泡出现。源码断言文件名与行索引相符；气泡图也取自对应 UI 内容。后一个回忆到来时前一个退去，尺度/光晕逐次增强，避免所有回忆同时抢焦点。

每次跳跃在起音帧落定，前面有两张在途帧；这和起音后才开始飞不同。笑声还用局部波形呼应音频文件，内容、位置与动作共同说明“正在读哪份记录”。

**可迁移选择**：建立写入→存在→选中→重现的事件链。跨段素材有可追踪身份；记忆文件名不仅是装饰标签。

## 8. 记忆气泡跟着文件名飞，碎片进入同一擦除流程

源码：[DSH/dsh_patch_mem.py:label_at/build_tiles/bubble_last/hidden_at](https://github.com/MisakaZentai/world-execute-me-dsh-pv/blob/a598092a1b1db91fa43961a81269353d13419f6f/film/pv_dsh_frontend_20260927/dsh_patch_mem.py#L188)，配合 `V2/s_reward.py:C55/C56` 与 `scenes_reward.py:defrag_cell/erase_sweep`。

最后气泡贴在正在飞行的文件名下方，位置和字号跟随同一 carrier。光标所在格被整理过程触及时，原主体层不再重复画它，由 overlay 接手；回窗实际覆盖到光标后才让它消失。

唱词触发擦除时，气泡按18×22格切块，只有有墨迹的块参与；按阅读次序在 .18 秒内错峰出发，每块飞 .32 秒，途中稍放大再缩为目标14×18格。目标候选避开主体占用格和应保留格，并筛掉过早被扫到的区域。

时间保证要准确：候选筛选要求 sweep 晚于**最早落地**至少 .12 秒；每块实际 `gone=max(自身land+.06,sweep_at)`，并在 gone 后亮闪两帧再移除。不是所有块都落地后固定停 .12 秒，也不能简单说全部在同一个 sweep 时刻立即消失。

**可迁移选择**：破碎物保留原贴图片段、目的格与消除事件；由下镜实际处理流程决定路径和生命周期。落地后果比“碎得好看”更重要。mem 补丁缺四张 sprite 中任一张会跳过，运行验证必须确认它已安装。

## 9. 过载终态由下一段继承；错误原因留下；墙真的挤压内容

源码：`DSH/batch_e.py:366–378,431–457,640–689`、`batch_f.py:70–85,282–344,557–691`、`dsh_patch_e.py:29–42`、`dsh_patch_f.py:56–90,151–218`、`dsh_patch_r1.py:121–137`。

## 10. 被选中的一个格，成为曲线头，再成为评分条终端

源码：`V2/s_eval.py:C87/C88(188–313),setup(896–898)`、`scenes_eval.py:177–207`。

178.774085秒，选中的回答 tile 先抬亮，其他 tile 向它排空；边框收拢，词沿弧线飞向 `chart_dots(0)` 的真实首点，途中变成蓝格。曲线等 .462 秒落地后才开始生长，蓝格继续位于曲线头，落地反弹也保留。

180.851008秒，C88 先扣掉 C87 的 DELAY，求到真实前镜进度；曲线点按顺序重排为条框，蓝格独立飞到评分条终端，数字转成百分形式。后续条从这个顶端条展开。

几何起点读实际延迟状态，载体数值则使用预定最终值，二者并非自动同一条数据计算。**可迁移选择**：选中的对象同时携带位置、颜色、尺度、意义与时间口径，跨多镜维持阅读定位；改场长时联动检查数值与几何。

## 11. 放大一个工作单元；用残点重启整个视口

源码：`V2/s_reward.py:C61(506–597),setup(758–759)`、`scenes_reward.py:418–430`；`s_eval.py:plain/C86(49–65,110–176)`。

C61 将一个专家格选中、放大到矩阵边界，再分成4×4格；过程中按当前尺度重绘格线与字号，避免仅放大低清截图。源格→目标 panel 有几何对应，矩阵值却由后镜生成，不代表读取了原专家内部数据。

这里有双时钟警示：DELAY 延后整份 scene t，而 split_at 仍取原歌曲绝对时间，冷却启动可能比按注释理解更晚。迁移时优先拆开歌曲时间和动作时间。

C86 则是另一类接续：从旧完整画面中心取残点颜色，把整帧压成横线，再从同一横线展开新完整画面。它保留视线锚点，却重置了整个世界；属于视口/遮挡合成，不是共享几何或同一三维相机。`plain()` 的 BYPASS 防止重新采样最终 frame 时递归进入自身 cut。

## 12. 撤销先前的禁止动作，最后让遗物变成未发送的新输入

源码：`DSH/batch_g.py:143–165,265–307,322–370,444–482`、[dsh_patch_g.py:logout/whale-fall/caret](https://github.com/MisakaZentai/world-execute-me-dsh-pv/blob/a598092a1b1db91fa43961a81269353d13419f6f/film/pv_dsh_frontend_20260927/dsh_patch_g.py#L72)。

旧问题以 recall 形式回来，但回答与最初不同；这不是用户已回来发新消息。logout 保留先前划叉，再按反向笔划撤掉，随后由角色自己的颜色按下；exited 状态由这次动作开始。左侧说话时右侧整体压暗，FINISH 仍局部恢复按钮亮度，让话语和行动能同时被读到。

归档冻结已有聊天，最后部分字符固定随机错峰松脱；relative offset 保留原行占位，字符变蓝、下沉、轻摆、退去，与外部海雪同向。只有尾部部分字符参与，不是整个窗口物理粒子化。

207.083秒硬黑之后，海底残留 cell 仍在；后来它用12帧沿浅弯曲线移到输入位置，最后35%路程从正方形变成 caret。目标来自不同输入文字状态的 DOM 实测坐标。问题逐字出现但没有发送，保留开放结尾。

## 研究使用边界

这些案例的本地运行采用仓库官方替身角色，不是原 B 站视频中的舞蹈。原生 Python/Pillow 与网页截图链保持原入口语义；新网页镜头仍按本机 Multiplane 制作流程，不能把既有 `.mjs` 截图器直接当作 Multiplane 项目。

源码可达、函数边界、实际画面和声音分别验收。静音抽样不会证明原音轨对齐；有限乱序检查不会证明所有镜头；源码中的边界风险也不自动等于公开视频里肉眼可见的坏帧。查阅本次证据目录与独立审计时保留各自范围。
