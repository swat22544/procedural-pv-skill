# 本地 PV 实践与证据边界

这里记录两个本地制作工程和一个后续样片如何参与技能沉淀。它们与外部四部参考作品分开署名；本仓库没有发布这几个工程的完整源码、媒体、音轨或私人研究目录。

## world.execute(me)：将语义、几何和发布流程接起来

有效记录为 V14 原生 4K 派生：3840×2160、24 fps、5398 帧、约 224.916667 秒，其中包含 13 秒发布片头。画面使用 NumPy/Pillow 的独立程序实现与 FFmpeg 输出；没有因为学习了 Three.js/Blender 就把它改写成那些引擎的作品。

设计上保留青色 ME 与金色 YOU 的双主体，在数学与计算机制中继续它们的身份和关系。几何变化先有语义事件，转场承接实际位置、路径或相位；字幕有独立的清晰布局。片头偏移仅放在发布层，歌内场景继续使用自己的歌曲时间。

它贡献给 skill 的主要内容：

- 全片设定与单镜头事件分开，防止每次改歌词都重置场景状态。
- 视觉隐喻、示意数值和真实计算分别说明，避免把 toy 机制包装成真实模型训练。
- 逻辑坐标与目标像素分开，让字形、线宽和后期在原生高分辨率重建。
- 分段编码、输入签名、媒体完整解码与编码后抽帧配合使用。

V14 的 720p 版本只在指定窗口重绘，其他部分复用已验证旧视频；4K 派生则完整重新计算全部画面。两种流程保留不同证据，不混称“全片重渲染”。旧 chunk 签名仅覆盖部分源码，不是完备资源签名；旧逐词时间仍是自动稿，没有声称逐句听校。

详细历史见 [案例默认值](../skills/procedural-pv/references/project-defaults.md) 与 [生产记录](../skills/procedural-pv/references/world-execute-workflow.md)。这些秒数、字幕和偏好只属于该案例。

## Machine Love：把状态、GPU 舞台和文字分开

有效记录为 V2：3840×2160、24 fps、6877 帧、约 286.541667 秒。NumPy 提供状态，ModernGL 绘制舞台，Pillow 合成清晰文字，再以 rawvideo 接 FFmpeg。

同一绝对时间的状态函数提供点、线、三角形、相机、视口和标签；舞台不自行推进模拟，也不偷偷生成新的对象身份。核心对象跨形态延续，语义进度完成后可以保持，载体运动则继续。复唱可以换歌词而保留已经成长的结构。

它贡献给 skill 的主要内容：

- 将计算、绘制、排版职责分离，减少时间和身份在多个模块间互相覆盖。
- 将相机与几何投影共享给世界标签，再用独立 alpha 层保证文字合成。
- 声学对齐交叉核对候选，保留源行与事件 ID 的区别、重叠与插值标记。
- 分析分轨与正式音轨分开，缓存与输入版本明确对应。

它使用了装有 Manim 的 Python 环境，但主体是 ModernGL 渲染，并非 Manim Scene。关闭深度测试的加法发光舞台适合点线，不等同于实体遮挡或 PBR；局部 halo 也不等同于完整 HDR bloom/色调管理。旧字幕调度仍固定 24 fps，旧 runtime NPZ 缓存检查也有局限，迁移需修正。

研究时复查了 7 个源文件哈希与既有 encoded manifest 的一致性；这次技能研究没有重新渲染整片或逐句听校。详细说明见 [machine-love.md](../skills/procedural-pv/references/machine-love.md)。

## 《把回声点亮 / ECHO, RETURNED》：把新方法放进同一段样片

这是一段 40 秒、120 BPM、1920×1080、60 fps 的原创编排音乐与歌词样片，使用 Multiplane 0.3.11 的本地安装与 Canvas 自定义透视，没有使用 Three.js 或 Blender。后续保留器乐，移除了合成人声。

样片尝试将地面文字的阅读与斜视揭示、路线到折痕再到翅膀的材料承接、文字独镜、暗场停顿，以及发送/接收/回应的状态关系编排在一起。某些镜头需要动，另一些需要等待；选用层正是为了保留这种差别。

本地交付记录覆盖 2400 帧完整解码与音频时间检查，仍不构成四种方法的普遍视觉质量证明。这里将它作为一次应用实践，不把它提升成下一首歌必须遵守的纸色、角色颜色、节奏或分镜模板。

## 怎样使用这些案例

读具体方法时，关注可迁移的因果、状态与检查条件；继续原工程时，再阅读它的历史默认值。没有拿到工程与资源，就不能执行文中旧发布器，也不能声称原成片已在新环境重现。

本 skill 的价值包含已有经验，也包含暴露出的局限。维护时应继续记录“改了什么、验证到哪里、还有什么没验证”，让后来的人能够知道哪些结论可以直接用，哪些需要重新检查。
