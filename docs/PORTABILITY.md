# 公开版与原本地版

公开版以 `2026-11-01-technique-selection` 本地 skill 为基础，版本记为 `2026-11-01-public.1`。保留原来的入口、宿主元数据与 21 篇参考文件，新增 `environment-setup.md`；四份 PV 研究、两个本地案例与 onetake 笔记继续可检索。

## 做了哪些适配

- 将原机器的用户目录、工具绝对路径、音频/视频路径与私人证据目录换成具名占位符。
- 给历史研究加上公开阅读约定，区分参考仓库文件、本地案例文件和未随包提供的证据。
- 给工具页增加跨机器的路线选择；历史版本、测试与未连接状态作为历史记录保留。
- 明确旧用户的工程偏好、路径、已授权操作和验证结论不会传递给新使用者。
- 在入口新增环境接入；新环境按自己的素材、工具和产物重新验证。
- 单独补充 README、工具清单、来源与许可、案例概述和示例分镜。

没有把资料研究变成一键渲染程序，没有安装或捆绑整套依赖，也没有以公开版覆盖维护者仍在使用的本地 skill。

## 如何阅读旧记录

原参考正文有明确日期以及“本次”“当前”等词；它们指研究发生时的状态。看到某个测试通过，应同时读取其覆盖范围。例如：单帧 EEVEE 通过不等于 Cycles GPU 或 4K 长片通过；一个窗口的确定性检查不等于全片穷尽检查。

`<REFERENCE_ROOT>` 可以对应读者自行取得的公共仓库。`<LOCAL_WORLD_PV>`、`<LOCAL_MACHINE_LOVE_PV>` 与 `<PRIVATE_STUDY_ARCHIVE>` 则不是本仓库内的目录，后者也不是供读者执行的依赖。占位符完整解释在 [环境接入](../skills/procedural-pv/references/environment-setup.md)。

## 后续维护

更新研究时记录来源版本、真实采用的方法、适用条件、反例与证据范围。新参考可以补充或纠正旧结论；若需要删除或替换，说明依据，保留来源关系，避免在扩展技巧库时丢失早期有价值的内容。

更新工具时先在独立工程检查接口和产物，不把本机新版本写成所有使用者必须立即升级的要求。新增加的风格方法应同时进入选用判断：适合什么观看任务、什么时候放弃、与其他方法如何安排主次。
